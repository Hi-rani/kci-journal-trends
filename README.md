# 국내 학술지 동향 분석 (Analysis of Korean Academic Journal Trends)

> **KCI 통계 기반 현황 진단과 국내 학계의 발전 방향 제언**  
> 20페이지 분량의 에디토리얼 데이터 저널리즘 스타일 인터랙티브 HTML 프레젠테이션 및 정책 분석 보고서

---

## 1. 프로젝트 개요

본 프로젝트는 한국연구재단(NRF) **한국학술지인용색인(KCI)** 포털의 최신 기관·학술지 통계(2026.10.23 기준) 데이터를 바탕으로 국내 학술 생태계의 현황을 실증적으로 진단하고 미래 발전 방향을 제언하기 위해 제작되었습니다.

단순한 현황 소개를 넘어, **실증된 사실(Fact)**, **데이터 기반 해석(Interpretation)**, **검증이 필요한 가설(Hypothesis)**, **정책적 제언(Policy Recommendations)**을 엄격히 구분하여 설계되었습니다.

## 3. 핵심 통계 요약 (기준일: 2026.10.23)

| 지표 구분 | 핵심 수치 | 점유율 및 세부 내역 |
| :--- | :--- | :--- |
| **전체 학술지 종수** | **6,359종** | 학회(3,466종, 54.5%), 대학연구소(2,664종, 41.9%), 일반(229종, 3.6%) |
| **등재(후보) 학술지** | **2,932종** | **전체 학술지의 약 46.1%** 등재 공인 |
| **등재 상태별 구성** | **우수등재 67종(2.3%)** | 등재 2,691종(91.8%), 등재후보 174종(5.9%) |
| **분야별 등재지 분포** | **인문사회 2,077종 (70.8%)** | 과학기술 855종 (29.2%) — 약 2.4배 격차 |
| **등재 발간기관 수** | **2,729개 기관** | 학회 2,118개 (77.6%), 대학연구소 498개 (18.2%), 일반 113개 (4.1%) |

## 5. 실행 방법

별도의 웹 서버나 빌드 도구 없이 모던 브라우저(Chrome, Edge, Safari 등)에서 즉시 실행 가능합니다.

### 5.1 로컬 열람
`presentation/index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 열거나 로컬 서버를 구동합니다:

```bash
# Python 내장 웹 서버 실행 예시
python -m http.server 8000
# 브라우저 접속: http://localhost:8000/presentation/
```

### 5.2 단축키 안내
- **이전 / 다음 슬라이드**: `←`, `→`, `PageUp`, `PageDown`, `Space`
- **처음 / 마지막 슬라이드**: `Home`, `End`
- **발표자 노트(Presenter Notes) 토글**: `N`
- **전체화면(Fullscreen) 토글**: `F`
- **인쇄 / PDF 저장**: 브라우저 인쇄(`Ctrl + P`), 페이지별 자동 분할 지원
